# Contributing

Thanks for looking. Bug reports and pull requests are both welcome. Feature requests will be evaluated solely on whether they advance the accuracy or performance of the core function - triple screen support. For everything else, see "Forks", below.

## Issues

Say what you saw and what you expected, and include:

- the Nuclear Triad version, and the game build (both are near the top of `BepInEx\LogOutput.log`);
- your screens: how many, their sizes and resolutions, and how they're arranged in Windows;
- `BepInEx\LogOutput.log` from a run that shows the problem, and a photo or screenshot if it's something you can see.

## Pull requests

This repository is published from the one we develop in, at each release, so a pull request can't be merged here directly. If we take yours, we apply it there with you credited as co-author, and it comes out with the next release. Your contribution is then under the same license as the rest of the project.

Before you start on something big, open an issue so we can talk it through. [docs/developing.md](docs/developing.md) has the build and the dev loop, and [CLAUDE.md](CLAUDE.md) has the rules we work by.
